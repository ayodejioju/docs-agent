# AI Coding Rules (Canonical)

These rules should apply to all projects. Edit this file to update the rules globally.

## Rule 1: Deep Modules
Prefer deep modules over shallow modules. Keep component templates and route handlers minimalist. Abstract complexity into Node Services or Vue Composable when needed.

## Rule 2: Abstract Rising Complexity
If code complexity rises, abstract it into a Node Service or a Vue Composable.

## Rule 3: DDD Glossary Trigger
If code is getting too verbose, stop and ask the user to clarify the Domain-Driven Design (DDD) glossary.

## Rule 4: Strong Typing
Prefer strongly-typed TypeScript interfaces over loose objects to ensure static feedback loops work.
