# Onboarding

## First week
New developers get repository access on day one and are paired with a buddy. Complete the secure coding module before your first merge to main.

## Local setup
Install Node 22, copy .env.example to .env, then run npm install and npm run dev. Never commit the .env file.

## Support channels
Ask questions in the engineering channel. Production incidents go to the on-call rota, not direct messages.
